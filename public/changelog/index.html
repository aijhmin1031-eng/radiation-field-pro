Changes between versions of Field Pro

Field Pro · updated 29 October 2026

This page records what changes from one version of Field Pro to the next. Anything that moves a calculated value or a verdict is listed first, ahead of changes to the screens and the pages, and the newest version comes at the top.

How versions are numbered

The version number moves in its middle place when a calculated value or a data table changes, as from 1.0.0 to 1.1.0, and in its last place when only wording or layout changes, as from 1.0.0 to 1.0.1. The version and its date appear above the footer of every page, and the printed report carries the version in its heading, so a result kept on paper can be matched to the version that produced it and to that version’s entry below.

1.0.1 — 29 October 2026

Filter thickness fields now accept steps of 0.001 mm (1 µm), matching a micrometre’s 0.001 mm scale, for both inherent and added filtration. The fields are wider so that a value such as 10.000 and the number arrows fit without hiding digits, including on narrow screens.

Previously the fields used 0.1 mm steps: the arrows moved in tenths of a millimetre, and browsers could mark an entered value such as 1.001 mm, or ISO preset thicknesses of 0.15, 0.18, 0.21 and 0.25 mm, as a step mismatch. Those warnings are removed. Entered values are retained without rounding in the calculation inputs, saved sessions and printed input summary. The calculation engine and data tables are unchanged; the same inputs produce the same calculated values.

1.0.0 — 29 October 2026

This is the first numbered version. Until now the workbench carried no number, so this entry is the reference point that every later one is measured from.

Calculated values

No calculated value has changed since the workbench was opened to the public at pro.radiation-lab.com on 25 October 2026. Between that day and this version no commit changed the calculation engine or its data tables, apart from the descriptive notes in the ISO 4037-1 table file, which were rewritten in English on 26 October without moving any tabulated value. The engine was written between 21 and 24 October and the screens on 25 October; the first deployment, that morning, opened only after signing in, so no one outside the project could rely on a result from before the public opening.

What results in this version rest on

  • Tube spectra: a tungsten-anode emission table generated with SpekPy 2.5.4 (casim physics, characteristic lines included, 20° anode) for tube voltages from 10 to 400 kV.
  • Attenuation: mass attenuation coefficients, and the mass energy-absorption coefficient of air, from 1 to 1400 keV, taken from the NIST data distributed with SpekPy 2.5.4.
  • Beam qualities: the 50 qualities of the L, N, W and H series in ISO 4037-1:2019, Tables 2 to 6.
  • Conversion coefficients: ISO 4037-3:2019, for Hp(10), H*(10) and H′(0.07).
  • Radionuclide sources: the half-lives of Cs-137 (30.08 years) and Co-60 (5.2711 years), with their gamma-line energies and emission probabilities, taken from evaluated nuclear data (ENSDF).

How closely this version reproduces the ISO tables is set out on the Validation page. If a later version replaces one of these tables, its entry here will say which results move, by how much, and from which date.

Screens and pages

  • 26 October: the interface became English-only. A quality picked from the ISO preset list now stays shown in that list instead of reverting to its prompt; choosing the same session or spectrum file a second time loads it again; and inputs saved, in a file or in the browser, under the earlier Korean default labels open with those labels in English.
  • 27 October: a plain description of the workbench was added below it, readable without JavaScript.
  • 28 October: the header, the footer and the light and dark themes shared across Radiation Lab; an address for the input and results views and for each panel, so that a panel can be linked to and the browser's Back button steps back within the workbench; a page for addresses that do not exist; and the Guide, Methods, Validation and About pages with three worked examples.
  • 29 October: the version line, this page, and the version in the heading of the printed report.
